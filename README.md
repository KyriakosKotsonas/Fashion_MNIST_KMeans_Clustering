# Fashion_MNIST_KMeans_Clustering

Unsupervised clustering of Fashion-MNIST with k-means, visualised with PCA and t-SNE.

## Notebooks

- `Kotsonas_Exercise4_10kMeanTSNE.ipynb`: k-means with 10 clusters, visualised with t-SNE
- `Kotsonas_Exercise4_20kMeanPCA.ipynb`: k-means with 20 clusters, visualised with PCA
